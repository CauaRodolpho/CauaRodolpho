Sempre foquei 100% no Front-end, mas chegou a hora de entender como as coisas funcionam do outro lado. Apanhei um pouco com o back-end, mas ver a primeira integração entre interface, API e banco de dados rodando liso na Vercel compensou demais. 😅
Esse é o AuthFlow, meu novo projeto voltado para autenticação e gestão de usuários. Ele começou como um estudo nas aulas da @DevClub, mas decidi ir muito além do tutorial: joguei a estrutura básica fora e reconstruí a aplicação do zero, aplicando a minha própria arquitetura, tipagem e design.
🤖 O papel da IA no meu aprendizado: Confesso que estruturar o back-end trouxe bugs e dificuldades que eu não estava acostumado a ver. Foi aí que utilizei a Inteligência Artificial não apenas para acelerar as coisas, mas como uma verdadeira mentora particular. Ela me ajudou a entender o "porquê" dos erros, me ensinou sobre a lógica das rotas e acelerou meu entendimento sobre arquitetura web.
Aqui está como dividi a arquitetura nesse desafio:
🎨 O que brilha no Front-end:
UI/UX: Interface responsiva com Tailwind CSS, animações fluídas (Framer Motion) e uma cena interativa em Spline 3D na tela de login.
Validação: Front-end (Vite/React) com comunicação 100% tipada e validada através do Zod.
⚙️ O motor no Back-end:
Dados & Arquitetura: API separada em Node/Express, criando um CRUD completo com painel administrativo conectado ao MongoDB através do Prisma ORM.
Segurança: Hash de senhas com bcrypt e controle rigoroso de rotas protegidas via tokens JWT.
Lidar com os famosos "erros de CORS" e o deploy independente das duas pontas na Vercel me deu uma visão muito mais madura de como a web funciona de ponta a ponta.
